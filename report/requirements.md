# AMD自主选题要求与目录对照

依据团队提供的2026年AMD选题指南，阅读器第22—26页对应页脚第19—23页。本文件是条款导航，不是测试完成声明。

## 分组与实现方式

- 第22页：初级组为大学一年级至三年级在读本科生；大学四年级及硕士生属于高级组。混合队伍按最高年级或学历分组。
- 两组提交内容与评测项相同，独立排名。
- 初级组可用7 Series、Zynq-7000、UltraScale及UltraScale+；RTL实现允许使用，PYNQ为推荐路线，不是必选。
- 第26页是开发板及其他资源获取说明，不构成我们必须改用借用板卡、Ryzen AI PC或GPU的要求。

## 工具、验证与开源

- 第23页：推荐Vivado/Vitis2026.1或2025.2；其他版本在报告说明并保证脚本复现。项目使用的2024.1须如实注明。
- 提交物须声明具体器件；作品须在板上运行并提供实测输出。
- 须提交大模型提示词、回答、自我纠错轨迹及可复用Skill。
- 强烈要求在GitHub或Gitee开源，允许再分发；本仓库保留已有MIT许可证。

## 工程包

| 第24页要求 | 本仓库位置 |
|---|---|
| 完整工程源码 | `src/` |
| 仿真或验证结果 | `sim/` |
| 综合、实现与资源时序报告 | `build/reports/` |
| 上板工程、运行脚本和实测输出 | `board/` |
| 实测与参考结果比对 | `data/`、`board/results/` |
| 可复现构建脚本 | `build/scripts/` |

## Skill与报告

- Skill独立置于`skill/`，`README.md`说明适用范围、使用方法、失效条件、已验证效果及失败或观察来源。
- 可以采用提示词工作流、案例模板、校验脚本、踩坑清单。评价重点是其他队伍能否迁移复用。
- 通用PYNQ Skill可另行加分，不能把普通RTL技能写成PYNQ技能。
- 报告需同时包括：背景创新和前人工作、原理框图、软硬件划分与接口、优化前后性能资源对比、AI协作记录、Skill提炼与验证边界、从零复现步骤。
- 完整AI材料与代表案例放在`report/ai_collaboration/`；技能和源码仍须独立提供。

## 命名与评分

仓库内目录和文件名使用英文，中文可写入正文。采用指南推荐的七个主目录；README和LICENSE等标准文件保留惯用名称。

| 第25页评测项 | 权重 |
|---|---:|
| 创新性与应用价值 | 30 |
| 性能与资源优化效果 | 20 |
| 功能正确性与设计完整性 | 20 |
| 大模型协作与技能包 | 15 |
| 文档质量与可复现性 | 15 |

优化应给出与基线的对比和判断依据；功能正确性与复现性主要依据提交物及实测数据核查。
