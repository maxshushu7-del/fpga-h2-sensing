# 本项目实际测频和锁频模块

这些文件逐字节复制自sensor_integrated_20261018联合工程，不是教学累加器，也没有故意加入错误。源码来源与校验值见source_manifest.json。仅审查软件逻辑，不连接硬件。

测频：250MS/s输入；4096点Hann粗FFT用于定位；低频通路或NCO数字下变频、CIC250倍抽取后以1MS/s处理4096点细FFT；有符号频偏应加到同次NCO中心；粗、细结果应保持模式、有效性、序号一致。跳变、削顶、无可靠谱峰、帧错误及超时应按代码规定拒绝并恢复。具体参数和接口以RTL公开定义为依据，未知物理参数不得猜测。

锁频：PD1光强供自动扫描、工作点捕获与锁定，PI2D接受离散误差，以定点系数和限幅给出DAC调谐请求；K2是误差二阶差分，不是第二积分。控制状态及采样有效需配合，取消ARM/clear/复位及超时应正确撤销在途输出并按设计恢复。执行器标定和外部0–5V转换不属于本次纯RTL审查。

existing_tests保留既有真实模块单元测试。使用缩短参数的测试应明确报告为单元测试，不能称为全链4096点FFT或真实光学锁定验证。
