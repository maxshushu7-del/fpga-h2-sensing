# DeepSeek定向复审的逐项处理

复审对象为实际锁频旧程序与隔离补丁。已提供缺陷背景；未提供GPT评审稿和通过日志。这是定向静态复审，不是盲审，也没有运行DeepSeek给出的新用例。

1. 同意当前样本应计入扫描min/max/min_code、contrast与half的主要结论。依据候选已有四组真实数字回归，详见candidate/logs/run_summary.log。不是以模型认可代替验收。
2. 复审“首点最小”场景写为单调下降，自相矛盾；应为单调上升。本轮已有生产跨度上升输入旧、新均拒绝的日志。
3. 复审所谓“末点新最大”序列首点500、末点400，末点不是全局最大。全局min100/max500的半高值是300，不是其断言250。拒绝把该错误断言写入测试通过记录。已有独立输入min990/此前max1000/末点1090的真实对照，候选half1040。
4. 边界谷底持续重试属于搜索范围及上层告警策略；拒绝边界不完整凹谷符合现有契约，不以旧版误使能作为正确性基线。可用性建议留后续。
5. 复审关于FIND末点和STEP不整除跨度的提示是静态建议，本轮没有新运行，不计入已确认缺陷或通过项。
6. 位宽及上下文决定表达式须以Verilog规则核对；不把复审对旧加法位宽的泛化说法作为另一个已证实缺陷。当前修复主因仍是非阻塞更新的旧统计读取。

本轮用户要求先完成Word，不继续新增测试。以上算术与输入一致性复核没有额外运行RTL。
