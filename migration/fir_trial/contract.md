# FIR迁移试用：本轮冻结的数值与接口契约

此规格由本轮编写者制定，用于技能试用，不是氢气装置需求。FIR类型此前仅在迁移计划中提到，具体规格和实现均为本轮新增；编写者同时执行验证，因此不是独立人员或盲测。

## 算法与数值

对按顺序接受的样本 x[n]，计算：

`s[n] = (3*x[n] - 2*x[n-1] + 5*x[n-2] - x[n-3]) / 8`。

输入、输出均为12位有符号整数原始码，范围[-2048,2047]，不绑定物理电压/单位。系数是精确分数，四个历史位置按接受事务计数，而不是每个时钟都移动。

最终整数舍入采用最近整数，恰好半整数时远离零；然后饱和到12位范围。不可回绕。RTL使用16位有符号累加器；数学最坏范围[-22525,22520]，该位宽足够。舍入前的绝对值和加偏置用17位，避免负极值问题。

例如：-3/8→0，-12/8→-2，12/8→2。输入8的孤立冲激，随后接受零，输出依次为3、-2、5、-1、0。持续接受8且历史填满时，输出为5。

## 时钟、接受与发布

- 单时钟，示例100MHz。同步高有效复位 rst。
- 在上升沿c，当 rst=0、enable=1、in_valid=1 时接受 x_in；没有 ready，不允许背压。
- 对未被取消的输入，out_valid 必须恰好在上升沿c+2置1，数据为该事务的舍入/饱和结果。可每拍接受和发布一个事务。
- 空拍不推进输入历史，但既有流水线继续运行。
- rst=1 或 enable=0 的上升沿，清零历史、在途流水线、out_valid与输出数据；该沿不接受输入。重新enable从零历史启动，不恢复旧状态。
- 输出数据仅在 out_valid=1 时有算法意义；复位/禁用沿后要求其为0。其余无效周期可保持。
- 三段寄存运算为累加、舍入、饱和输出；“c+2”是准确延迟约定，避免只写“三级流水”造成歧义。

## 参考与身份

Python参考以精确有理数卷积计算高精度输出，再按契约量化；另以整数累加/舍入作交叉检查。手算冲激、恒定输入、正负舍入与饱和极值检查参考本身。

每个接受事务的sample_id取全局输入周期号，跨复位不重置。DUT不传递ID；testbench用固定延迟契约核对逐周期发布，并按到期ID导出数值。unexpected周期会使用独立错误ID。CSV比对不能脱离逐周期检查而宣称身份/时序正确。

精确数值容差0。不因某个实现失败而放宽容差，不移动CSV行掩盖错拍。

## 验证范围

覆盖正负极值、冲激、直流、正负半整数、正负饱和、空拍、连续输入、忽略的无效输入、计算途中复位/禁用、固定种子随机场景及结束排空。

至少需要数值参考一致和每周期valid/复位行为同时通过。另运行明确标注的舍入、符号扩展和valid错位注入变体，要求检查器拒绝它们；这不是自然产生的bug或统计成功率。

此任务没有CDC、可变延迟、动态系数或真实模拟接口。不验证跨板卡、ADC、激光、TEC或物理稳定性。
