# 仿真与验证

| 子目录 | 内容 |
|---|---|
| `testbench/` | 模块、完整测频链和数字协同的testbench |
| `scripts/` | 编译、运行及自动比对入口 |
| `results/` | 对应源码与输入的原始日志、波形和结果摘要 |

每组结果应记录源码版本、参数、输入条件、工具版本、命令、预期输出、实际输出和退出状态。参考数据见[data](../data/README.md)。有测试源码不等于测试已通过，历史日志与新运行日志分别保留。

数字模型、模块单测和完整数据链验证分别说明范围；板级输出归入[board/results](../board/results/)。
