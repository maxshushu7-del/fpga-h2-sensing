# 构建与实现

| 子目录 | 内容 |
|---|---|
| `scripts/` | 从源码创建工程、生成IP、综合、实现及生成bit的脚本 |
| `reports/` | 同一器件、同一顶层和同次实现的综合、资源、时序、路由及检查报告 |

构建说明应列明Vivado版本、器件型号、依赖、工作目录与完整命令。使用其他工具版本时，按AMD指南在报告说明并给出可复现入口。

归档资源和时序结果时同时保留完整报告，区分已约束路径满足要求与外部接口的板级核验。构建所生成的大量缓存与中间网表不作为默认源码内容上传。交付用bit/ltx见[board/bitstream](../board/bitstream/)。
