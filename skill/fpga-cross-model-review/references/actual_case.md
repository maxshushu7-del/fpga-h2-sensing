# 实际FFT测频与锁频实例

主材料在[案例目录](../../../migration/project_cross_review/README.md)。39份实际工程快照没有人为插入故障。

GPT发现auto_lock_fsm在SWEEP最后采样点使用非阻塞赋值更新前的旧极值作资格判定。ADC随扫描单调下降时，旧版可能把端点最小误当成内部谷而进入LOCKING。隔离候选将当前采样纳入min/max/min_code后统一判定，并计算完整幅差与半高值。已有日志保留旧版误接收、候选拒绝、末点新最大值以及既有捕获/失锁/重获/平光回归。

DeepSeek获得旧、新源码与缺陷背景进行定向静态复审；没有进行盲审或运行工具。它同意主要修复方向，但部分建议输入不符合自身假设：首点最小应使用上升而非下降序列；声称末点新最大却给了更高首点，因而半高断言也不成立。执行侧按全局极值纠正，另将FIND残留及范围外捕获建议保留为静态事项，未因此继续新增测试。

可迁移经验是：审查意见也要审查，输入与断言须成对核对。一个模型的反对或两个模型的一致都不能替代实际运行记录。此流程产生了本项目真实缺陷的可查证补丁，但不据单次过程宣称全球新算法、通用节时比例或模型能力排名。

测频验证另有18例既有估计器、4096点19例及真实AMD FFT模型5MHz粗细全链。PI2D和FSM属于数字功能检查；光学反馈和时序实现保持独立评价。
