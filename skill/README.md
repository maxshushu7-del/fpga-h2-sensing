# 可复用技能包

本目录用于提交从工程实践和大模型协作中提炼的可复用经验，对应AMD指南3.3.5.2。中文可以写在文件正文，目录及文件名使用英文。

| 技能入口 | 任务与适用场景 |
|---|---|
| `fpga-rtl-verification/` | 已明确算法、位宽和握手契约的定点RTL验证 |
| `fpga-vivado-diagnosis/` | 结合完整工程、约束和报告定位Vivado实现问题 |
| `fpga-cross-model-review/` | 实现模型与独立审查模型寻找反例并验收修正 |
| `cases/` | 原始问题、提示词、模型回答、修正和回归案例 |
| `migration/` | 换模块或任务后的迁移材料与验证结果 |

每项技能应补齐：

1. 适用场景和不能使用的条件。
2. 输入材料、工具与依赖。
3. 可执行步骤、提示词模板及需要的脚本。
4. 输出和验收标准。
5. 已验证效果及其日志。
6. 提炼该经验的失败、观察或反例。
7. 迁移时需要重新确认的接口、参数和边界。

Skill可以包含提示词工作流、案例模板、校验脚本或踩坑清单，不以介绍本项目为唯一用途。归入真实技能材料时保留案例内部的目录关系，并同步所有相对引用。关于协作过程的报告叙述见[AI协作记录](../report/ai_collaboration/README.md)。
